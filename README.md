# upsaf ( Update System, AUR, and Flatpak )
A CLI Bash script to update CachyOS system, AUR, and Flatpak packages \
it runs cachyos-rate-mirrors, then paru, then flatpak update, and at the end it will give you a list of all updated packages

# How to use it ?
type upsaf in your terminal / shell, then upsaf will run directly

# How to install it ?
download the upsaf.sh from the repository \
run the command
```bash
sudo cp /path/to/your/upsaf.sh /usr/local/bin/upsaf
```
change ( /path/to/your/upsaf.sh ) to the actual path where you saved the upsaf.sh file
